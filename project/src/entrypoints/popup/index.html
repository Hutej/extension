What WebMorph sends to the AI:
When you transform a page, WebMorph reads the page's structure (text content, layout, colors, fonts) and sends it to your configured AI model (Cloudflare Workers AI). Form input values, passwords, and credential-shaped strings are redacted before sending. The AI returns a redesigned style that WebMorph applies locally. No page content is stored on any server.
