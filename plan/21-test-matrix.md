## Matrix execution rules

- Test IDs remain stable across file moves. Add case suffixes (T14-a, T14-b) in implementation evidence rather than renumber.
- Each task lists required rows. Mark a row passed only with real command/browser evidence and supported-version result, not a reasoning review.
- A manual platform constraint unresolved by automation is an open release blocker for that advertised capability. It is not an automatic skip or reason to drop the capability from traceability.
- Negative controls prove missing verification, wrong target, clone restore, zero-test run and model-generated script cannot pass.
