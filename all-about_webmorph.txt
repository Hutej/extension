# What is WebMorph?

WebMorph is an AI-powered browser extension that allows users to completely transform any website using natural language.

Examples:

* Hide YouTube Shorts permanently.
* Remove the Twitter "For You" tab.
* Tranfer this site to neobrutalism style/theme
* Auto-collapse Reddit comments.
* Tranfer this site to glassmorphism style/theme
* Turn GitHub Pull Requests into a Kanban board.
* Make Gmail keyboard-first.
* Hide LinkedIn engagement bait.
* Move Spotify's player into a floating mini-player.
* Turn Wikipedia into a magazine.
* Turn YouTube into Spotify.
* Turn Amazon into Apple.
* Increase spacing.
* Reduce clutter.
* Replace layouts.
* Add shortcuts.
* Rewrite workflows.
* Modify interaction behavior.

The user describes what they want.

WebMorph does everything else.

---

# The Product Goal

The goal is NOT CSS generation.

The goal is NOT theming.

The goal is NOT dark mode.

The goal is NOT reader mode.

The goal is NOT userscripts.

The goal is NOT building another browser.

The goal is to allow users to reshape any website's:

* Layout
* Appearance
* Density
* Navigation
* Workflow
* Interaction
* Keyboard shortcuts
* Behavior

while preserving the original website functionality.

The backend never changes.

The website never changes.

Only the user's experience changes.

---

WebMorph in terms of product capabilities:

Observe a website.
Understand what the user wants.
Decide what should change.
Apply the changes safely.
Keep those changes working as the page updates.

---

# Product Philosophy

The browser already knows how to render websites.

We do not replace the browser.

The runtime already knows how to mutate websites.

We do not replace the runtime.

The AI should understand user intent.

The runtime should execute safely.

The browser should continue functioning normally.

---

# What Has Already Been Proven

The following knowledge is considered validated.

Do NOT reinvent it.

## Browser

We understand browser execution.

We understand CSS execution.

We understand MutationObservers.

We understand browser constraints.

We understand DOM mutation safety.

We understand browser physics.

These are solved.

---

## Runtime

A deterministic runtime is required.

The runtime should execute instructions.

The runtime should NOT perform reasoning.

---

## AI

The AI should perform reasoning.

The AI should never execute browser logic.

---

## Website Understanding

Raw DOM is not suitable for AI reasoning.

Semantic understanding is significantly better than raw DOM for planning.

The AI needs meaningful concepts rather than noisy browser structures.

---

# What Is NOT Solved

The following remain open problems.

* Transformation planning.
* Converting user intent into execution.
* Representing transformations.
* Universal operation language.
* Behavior modification.
* Workflow rewriting.
* Persistent customizations.
* Robust semantic understanding across arbitrary websites.

These are our primary focus.
